This project predicts crime categories using machine learning models and provides an interactive dashboard built with Streamlit. It is based on Northamptonshire crime data and includes full data cleaning, EDA, classification modelling, performance evaluation, and dashboard deployment structure.

Features

Data cleaning & preprocessing

Exploratory Data Analysis (EDA)

Random Forest / Logistic Regression / Decision Tree models

Geo-based and time-based insights

Interactive Streamlit dashboard

Feature importance analysis

Train/test performance comparison

Tech Stack

Python (Pandas, NumPy, Scikit-Learn)

Streamlit

Matplotlib / Seaborn

Jupyter Notebook
